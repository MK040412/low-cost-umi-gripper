# Sensors Guide

This guide covers the sensor modules used in the Low-Cost UMI Gripper.

## Overview

The sensors module provides affordable alternatives to expensive sensors typically used in manipulation systems.

## Sensor Types

### Force Sensors
- FSR (Force Sensitive Resistors)
- Load cells
- Tactile sensor arrays

### Position Sensors
- Rotary encoders
- Potentiometers
- Hall effect sensors

### Vision Sensors
- USB cameras
- Depth cameras (optional)

## Sensor Specifications

| Sensor Type | Model | Cost | Accuracy |
|-------------|-------|------|----------|
| Force | FSR 402 | ~$5 | ±5% |
| Encoder | AS5600 | ~$3 | 12-bit |
| Camera | USB Webcam | ~$20 | 1080p |

# Contributing Guide

Thank you for your interest in contributing to the Low-Cost UMI Gripper project!

## Ways to Contribute

### Report Bugs
- Use GitHub Issues to report bugs
- Include detailed reproduction steps
- Attach relevant logs or screenshots

### Suggest Features
- Open a GitHub Issue with the "enhancement" label
- Describe the feature and its use case
- Discuss implementation approach

### Submit Code
- Fork the repository
- Create a feature branch
- Submit a Pull Request

### Improve Documentation
- Fix typos or unclear explanations
- Add examples or tutorials
- Translate documentation

## Development Setup

### Clone the Repository

```bash
git clone https://github.com/MK040412/low-cost-umi-gripper.git
cd low-cost-umi-gripper
```

### Install Development Dependencies

```bash
pip install -r requirements-dev.txt
```

### Run Tests

```bash
pytest tests/
```

## Code Style

- Follow PEP 8 for Python code
- Use meaningful variable and function names
- Add docstrings to functions and classes
- Write unit tests for new features

## Pull Request Process

1. Create a feature branch from `main`
2. Make your changes
3. Run tests and ensure they pass
4. Update documentation if needed
5. Submit PR with clear description
6. Address review feedback

## Code of Conduct

- Be respectful and inclusive
- Welcome newcomers
- Focus on constructive feedback
- Collaborate openly

## Questions?

Feel free to open an issue or discussion for any questions!

# Low-Cost UMI Gripper Wiki

Welcome to the Low-Cost UMI Gripper project wiki!

## About This Project

This project aims to create an affordable version of the UMI (Universal Manipulation Interface) Gripper by replacing expensive sensors and hardware with low-cost alternatives while maintaining functionality.

## Project Modules

### Hardware
Low-cost alternative hardware designs and 3D printing files for the gripper mechanism.

### Sensors
Affordable sensor solutions including force sensors, position encoders, and camera modules.

### Software
Control software, drivers, and ROS integration for operating the gripper system.

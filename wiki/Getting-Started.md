# Getting Started

This guide will help you get started with the Low-Cost UMI Gripper project.

## Prerequisites

### Hardware Requirements
- 3D printer (for printing gripper parts)
- Basic electronics tools (soldering iron, multimeter, etc.)
- Computer with USB ports

### Software Requirements
- Python 3.8+
- ROS2 (optional, for robotics integration)
- Arduino IDE (for microcontroller programming)

## Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/MK040412/low-cost-umi-gripper.git
cd low-cost-umi-gripper
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Hardware Assembly

See the [Hardware Guide](Hardware-Guide) for detailed assembly instructions.

### 4. Sensor Calibration

See the [Sensors Guide](Sensors-Guide) for calibration procedures.

### 5. Run the Software

```bash
python software/main.py
```
